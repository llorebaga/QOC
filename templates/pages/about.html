About QOC

QOC is a living map of quantum optimal control: a place to learn the field, follow it as it evolves, and see where its open questions lie.

Why this site

Quantum optimal control is spread across physics, chemistry, applied mathematics and engineering, and across many experimental platforms. Its knowledge sits in reviews, theses and thousands of papers that use different notation. QOC collects the essentials in one place, organizes them into a map, and keeps that map up to date as new work appears.

It is written for anyone interested in the field: students starting out, researchers moving in from a neighbouring area, and practitioners who want to keep track of what is happening.

How it is built

  • Plain text. Topics, groups and open problems are stored as Markdown and YAML files in a git repository. Every change is versioned.
  • One shared map. A single taxonomy of the field connects topic articles, papers, research groups and open problems.
  • Automation where it helps. A scheduled job fetches new papers from the arXiv API every day and classifies them into topics.
  • Static and fast. The site is plain HTML, CSS and JavaScript, generated by a small Python script — no server, no tracking.

Contribute

QOC is still in private development. Once it is public, corrections and additions — a missing group, a new open problem, an error in an article — will be welcome as issues or pull requests on GitHub. Every data file is plain YAML or Markdown, so no web-development knowledge is needed.
